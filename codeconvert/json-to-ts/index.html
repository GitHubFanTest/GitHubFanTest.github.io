why this exists

writing interfaces by hand for a deeply nested API response is slow and easy to get wrong — miss one optional field or mistype a nested array and TypeScript will complain the whole way down. this tool reads the actual shape of your JSON and generates matching types in one pass, including nested objects as their own named interfaces.

everything runs client-side in JavaScript. your data is never sent anywhere.
