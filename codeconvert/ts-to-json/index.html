why this exists

sometimes you have the types before you have real data — building a UI against an interface that isn't wired up to a live API yet, or writing a test fixture. hand-writing a JSON object that matches a type is easy to get subtly wrong (miss a field, wrong nesting). this tool reads your interface definitions and builds matching sample JSON automatically, including nested interfaces and arrays.

everything runs client-side in JavaScript. your code is never sent anywhere. this covers common patterns — plain interfaces/types, nested objects, arrays, optional fields, and basic unions — but very advanced TypeScript (generics, mapped types, conditional types) may not convert perfectly.
