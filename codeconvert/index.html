small, free tools that turn one format of code into another. runs entirely in your browser — nothing gets uploaded anywhere.

paste a JSON object, get a clean TypeScript interface. handles nesting, arrays, and optional fields.
JS → TypeScript (coming soon)
add type annotations to plain JavaScript.
JSON → Python dataclass (coming soon)
turn a JSON response into a Python dataclass.
